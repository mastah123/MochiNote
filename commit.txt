Version semantics
  fix:   patch  (1.0.0 → 1.0.1) — Bug fixes
  feat:  minor  (1.0.0 → 1.1.0) — New features
  feat!: major  (1.0.0 → 2.0.0) — Breaking changes

Format: <type>: <previous_version> → <new_version> — <summary>, then Fixed / Added / Changed / Impact (only the relevant sections).
New entries go at the top, below this legend.
