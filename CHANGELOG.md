# Changelog

## 0.1.0 - Batch K1
- Gradle project: Compose + Material 3, Room, DataStore, Navigation.
- Mochi theme (light and dark) with the web app's pastel tints.
- Home: time-of-day greeting with your name, New Note, folder tiles with New folder, Recent Notes, banner.
- First-run welcome dialog asking for your name.
- Plain-text note screen with autosave and Move to Trash.
- GitHub Actions workflow building the debug APK on `kotlin-app`.
