# MochiNote (Kotlin)

Native Android version of MochiNote, built with Jetpack Compose, Room and DataStore.
Lives on the `kotlin-app` branch.

## Build
Push to `kotlin-app`: GitHub Actions builds the debug APK (Actions > latest run > Artifacts > MochiNote-kotlin-apk).
Locally: open the folder in Android Studio and run `app`.

## Batches
- K1 Foundations + Home (0.1.0)
- K2 All notes, Categories, pin/archive/trash
- K3 Rich-text editor
- K4 Images, cards, templates
- K5 Settings, themes, backup/import, profile
- K6 Reminders, share, streak, trash auto-clean, backup nudge
- K7 Polish, tests, release signing
